# Every published screenshot (docs/generated/screenshots/<name>.svg), grouped
# under the capture executable that draws it: a `[capture_<tool>]` line opens
# a group, and each name below it is one figure that tool writes. The groups
# are the whole truth in both directions:
#
# - tests/CMakeLists.txt registers one `<name>_visual_capture` CTest per group
#   (<name> is the tool's name without `capture_` and `_screenshots`), which
#   runs the tool and requires it to write exactly the group's figures, each
#   byte-identical to the published copy (tests/check_screenshots.cmake);
# - tools/docgen/check_docs.py --screenshots requires every published SVG to
#   be named here, every name to be referenced by client documentation and
#   every reference to be named here, and every group to name a tool with a
#   source file in tools/docgen/.
#
# tools/docgen/generate_docs.sh builds and runs the tools named here.
