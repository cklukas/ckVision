# WP-38 milestone traceability — 2026-09-26

This is WP-38's release traceability report. It maps every literal exit
obligation of milestones M0–M11 in [ROADMAP.md](../ROADMAP.md) to its
corrective work package and implementation, the executable evidence (unit,
script, golden, fuzz, benchmark, recorded host run), and the public
reference. It changes no milestone status. The
[acceptance status table](../ROADMAP.md#current-acceptance-status) stays the
authority, and a milestone moves to `Done` only when every row below is
**Done**.

Each row has one of three results:

- **Done:** an executable test, golden, gate, or recorded run checks the
  literal obligation.
- **Gap:** the evidence is missing, substituted, smoke-only, or has no
  documentation. The gap list under each table names the fix.
- **Owner:** the evidence needs an act only the project owner can supply:
  a sign-off, an interactive session on a named machine, a timed walkthrough,
  or a reference-machine measurement.

Code existing is not evidence. A row is **Done** only when something
executable fails if the obligation stops holding.

The rows were drafted by reading the repository at `6891c3c` and grepping for
every cited file and test case. They now reflect the wave-1 fixes merged into
the working tree since then, and the owner decisions D-081 to D-086. Every
case, golden and gate those fixes added was grepped again before a row changed
its result.
