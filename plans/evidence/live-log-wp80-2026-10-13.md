# WP-80 private process-stream evidence — 2026-10-13

Implementation is complete; full acceptance remains pending. D-142 and the
live-log architecture derive behavior from ckVision contracts and published
platform APIs. No outside implementation source was consulted.

## Delivered behavior

Core ProcessStreamService/Session exposes bounded launch requests, distinct
stdout/stderr identities and epochs, independent mailbox policies, root/exit/
native-error observations and nonjoining cancellation. term prestarts 1–8 owned
workers and native wake transports. Source selection moves bounded state, while
launch/I/O/cleanup run on the worker. Session state survives retirement until
the worker releases it; no worker owns or calls a view.

Finite and continuous adapters share the native private pipe pump and launch
preparation. Each blocked output retains one native chunk/publication packet;
the other stream still progresses. Busy yields; actual backpressure waits for
capacity/cancellation readiness. Quiet streams never time out. Native root
readiness uses macOS process events, Linux pidfd when available and Windows
handles, with explicit polling fallback. EOF is observed independently per
pipe. Root completion kills owned descendants and drains ready buffered bytes
without waiting for unrelated descendant EOF. Unverified tail closure is explicit.
Overlapped cancellation observes completion before releasing its buffer and
preserves a positive read which wins that race. No helper bytes reach the host
terminal. Cancellation, publication failure and overflow loss remain distinct.
