# WP-76 file follower validation

LogFollower composes injected sessions and the bounded model on the owning UI
thread, with explicit monotonic time and preallocated payload/path/tail storage.
Each step consumes one publication and delivers one byte quantum. Startup tails
scan at most 64 KiB, select newest lines, and explicitly discard unverified
leading fragments. File EOF preserves partial identity; stop/source changes
finish partial text as incomplete. Overlap probes detect boundary rewrites and
truncation without re-appending their bytes. Legal short reads may split a probe
or complete only its overlap; the fixed regression verifies continued reads at
the cursor. Path reconciliation drains the opened object only by quota. Native
identity changes, reconnect and truncation separate generations; uncertain
continuity and known skipped bytes are reported separately from model eviction.

The unreleased request interface now borrows an immutable request for immediate
adapter copying. The adapter exposes its read admission limit; generation start
explicitly controls BOM handling at nonzero source offsets. No filesystem,
locale or clock access enters widgets, and no dispatch-time heap allocation
occurs in start/delivery/reconciliation. Source/model history survives errors
and source switches; stale results are rejected by revision. Deadline arithmetic
saturates without recurring work at a terminal clock value.

The current code passes **54 cases on macOS and the Debian ARM64 VM**:
4 source contracts, 15 model, 12 source adapter and 20 follower cases under
ASan/UBSan, plus three independent allocation cases. **Mac CTest 11/11** includes
both provenance checks, layer/license guards and their self-tests. **VM CTest
5/5** covers the source/model/adapter/follower/allocation suites. Zero warnings
were emitted by direct strict-warning compiler invocations. There is no cache
wrapper or claimed timing benchmark. A failed first short-read test was fixed
before this checkpoint; current suites all pass.

The 20 follower cases cover bounded initial reads and reconciliation, append
between initial inspection and tail read without a hint, unfinished-line
identity, newest-line tail selection, large-file bounded windows, discarded
prefix through a split CRLF, literal BOM at nonzero offsets, short probe reads,
copy-truncate, same-size rewrite/truncate-regrow, metadata-only change without
history replay, missing/denied/reconnect, periodic missed-hint recovery, lost
notification warnings, source-switch stale results, drain-quota loss accounting,
invalid publication/backwards time, saturated deadlines, real pathname rotation
and real open-file following of a rotated object.

Native unit scenarios run on the exact compiled test executable, not an app
copy or rendered fixture. No application window or visual fix is claimed here.
Mac scratch remains on S8T; the existing VM's active task workspace uses the
permitted PRO-BLADE temporary share. Other tasks' completion code, VM disks and
builds were preserved. Current source/output hashes were checked after tests.
Superseded WP-75 local executables were removed after preserving its durable
record; the current workspaces remain needed by WP-77.
