# WP-78 incremental query/search evidence — 2026-10-13

WP-78 implementation is complete; global gates remain pending. The behavior
comes from D-140's bounded query/publication contracts and ckVision's Unicode,
identity and text-layout specifications. Executable evidence uses the project's
own scripted inputs and pinned frames, not outside implementation comparisons.

## Delivered contracts

LogLiteral compiles bounded UTF-8 literals with exact/ASCII-insensitive policies
and resumable comparison quotas. LogFilter owns two fixed ID rings, compiled
include/exclude/field predicates, severity/source gates, query revisions and
bounded partial snapshots. Empty unrestricted queries project the model in O(1).
Incremental admission, binary prefix eviction and atomic query publication need
no mutation-time allocation or whole-history refilter after ordinary append.
Partial snapshots keep the old query's displayed bytes coherent until matching
of new text finishes. Text revisions distinguish content from discard/decoder
bookkeeping; progress replacement still invalidates matching.

LogSearch supplies independent next/previous/wrap requests with captured upper
admission bounds and current ID/text/visibility/query checks at delivery.
Eviction marks a request incomplete. Visible-window highlighting includes
bounded pattern overlap and merges overlapping ranges before marking bytes.
LogView reveals whole touched graphemes, including a visible newline selection
cell for explicit multiline records. Detail/context lookups preserve raw data
and do not expand the primary filter index.

LogPanel binds the shipped filter, optionally binds Find, exposes Ctrl+F/F3/
Shift+F3, and labels errors/rebuild/catch-up/no-match/stale states. Alt+F3 remains
window close. SearchBox's injected prompt distinguishes Filter/Find fields.
The former misleading panel search() accessor is replaced with filter_box();
all callers/tests/docs are updated. Source and custom-query pending state are
separate properties. The app schedules steps; keyboard/paint never scans history.
