# p99 event-to-bytes runs on the reference host — 2026-09-26

This record is evidence for the ROADMAP M3 exit item "p99 < 2 ms event-to-bytes
measured by the scripted PTY harness with timestamped injection on the
reference machine". The harness is `cvision_pty_latency`. Its method is
described in [performance.md](../../docs/performance.md#the-pty-harness), and
the limit comes from ARCHITECTURE.md §8.

## Verdict

**p99 < 2 ms is not yet established under the procedure's conditions.** The
procedure asks for an otherwise idle host. Another project's builds and VMs
loaded this machine throughout the session. The 1-minute load average never
fell below 27 on 10 cores. Of five Release runs, the limit held in two: run 3
at a 1-minute load of 32 had an overall p99 of **0.969 ms**, and run 2 at 37 had
**1.299 ms**. It was exceeded in the other three, at 6.1 to 15.0 ms: run 1 at
load 109, run 4 at 36 and run 5 at 49. Seconds apart and at similar loads, runs
2, 3 and 4 differ by a factor of six in p99. p50 stayed between 0.23 and
0.56 ms in every run. The tail follows the host's load rather
than ckVision's work: the frames are the same size in every run, and the rehearsal
proves each operation presents exactly one frame. Establishing the baseline
still needs a run on an idle host, which is the owner's act. Run 3 below is
the best candidate so far.

## Configuration

The harness used its defaults: 10,000 timed operations after 4 discarded
warm-up cycles (100 operations), on a 200×60 PTY. The capability profile was
the `ModernVt` baseline with true colour and synchronized output (DEC 2026),
probes off. The mix is 400 cycles of 25 operations: 4,000 echo, 1,600 focus,
400 menu opens, 1,200 menu navigation steps, 400 menu closes, 1,200 window-move
drag steps and 1,200 resize-grip drag steps. Every run passed the headless
rehearsal. Every child exited cleanly, and no run saw a frame that no operation
asked for. Mean frame sizes were identical in every run: echo 92 bytes, focus
270, menu open 1,681, menu navigation 238, menu close 1,513, window move 2,819,
window resize 3,301, overall 971.
