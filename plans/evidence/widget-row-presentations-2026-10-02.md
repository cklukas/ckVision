# Row presentations implementation evidence, 2026-10-02

D-119 ListView/Table: optional alternating rows, optional Table column rules,
independent list/table band and divider roles. Defaults remain Plain. Absolute
display-row parity survives scrolling/sorting, and explicit item/cell styles,
selection and editing supersede banding. Rules occupy the existing gaps and
preserve cell widths, hit positions, header resize/sort boundaries and editor
identity. Their foreground accent retains the header/row surface beneath it.

Materialized row text and headers are borrowed during paint. Provider numeric
values use a fixed local formatting buffer, shared with the canonical public
formatter. No provider-return ownership contract changed. The allocation gate
proves zero steady allocations for long materialized Unicode rows and headers
in all four combinations of the two Table settings and both ListView styles.
Provider-owned allocations in a value-returning callback are not claimed by
that measurement. Behavior tests cover parity after scrolling, explicit styles,
selection identity, divider cells/background, mouse cell coordinates, empty
rows and disabled surfaces. Existing canonical value-format tests remain green.

The verified macOS Release incremental build passes 218/218 CTest gates
(22.59 seconds), including provenance/self-test, architecture, documentation,
raw generated bytes, appearance, package/install and benchmark budgets. The
adjacent JSON records build times, exact output/executable identity and a
fingerprint of the source/assets verified unchanged since that build.
A failed intermediate build omitted a test's sort-direction argument; it was
corrected and rebuilt before accepting the allocation result. The accidentally
run prior executable was discarded as evidence for that failed source state.

New goldens: 24 ListView and 84 Table dumps across four schemes, including
focused/disabled/scrolled/sorted/editing/Unicode/narrow states as applicable.
The matrix was inspected as compiled scene images, including Light, Dark and
Monochrome alternatives. No running app was launched or claimed visually fixed.

This is the fourth implemented review row, not completion of the full goal.
Nine rows remain, followed by feature-frozen clean macOS/Linux/Windows builds,
fuzz corpora and sanitizer verification. No commit was made for this batch.
