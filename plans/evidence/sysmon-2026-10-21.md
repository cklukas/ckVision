Native probes exercised macOS, Linux and the two-GPU Windows workstation.
Windows physically linked cards shared a LUID; their physical indices and PnP
PCI identities kept dedicated/shared memory and NVML telemetry separate.
Both native and SSH paths reported loaded Ollama models. SSH fallback was
exercised against Linux and Windows, including a sanitized Windows query.

The initial Windows install-consumer check exposed an existing single-config
Debug/Release ABI mismatch; passing the installed configuration at configure
time fixed it. A loaded parallel ConPTY run had a process-count timing failure;
subsequent complete four-way Windows runs passed. No failing gate is hidden.

The [machine-readable receipt](sysmon-2026-10-21.json) records source/asset and
executable fingerprints, build start/end/durations, configurations and exact
output paths. macOS rebuilt all 606 Ninja steps with no compiler cache/launcher
and zero warnings. Windows started with a clean build; Linux started in an
empty task workspace. Final changed inputs were rebuilt and their bytes checked
against the same input manifest on every host. Charts have no bundled runtime
assets. Historical timings are contextual evidence; they do not prove freshness.

Computer-use denied Terminal access. Actual native-window visual inspection
therefore remains unverified. The preview and goldens use the real application
with fixed data through its headless path; they do not substitute for inspecting
a live terminal window. macOS GPU utilization/capacity remain explicitly absent
where the public Metal APIs provide only process allocations or budgets.

Behavior derives from ckVision's own desktop/menu/status/calendar APIs and
published platform/OpenSSH/NVML/Ollama interfaces; no prohibited implementation
source was consulted. Both mandatory provenance gates passed. Sanitizer build
trees and disposable task outputs are removed after retaining this receipt and
logs; only the current runnable builds/workspaces remain.
