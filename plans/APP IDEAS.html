ckmath · application map

What you can build on an exact,
honest math engine

ckmath is not another computer-algebra system. It is a deterministic, exact-first math engine whose value is trust: every answer arrives as value + the domain it's valid in + how sure we are, every derivation is a replayable, machine-checked object, and the same input produces the same bytes on every machine, forever. That specific character — not raw breadth or speed — decides what it is uniquely good to build.

Exact
1/3 + 1/6 is 1/2, and x+1 where x≠1 — it refuses rather than guesses.
Checkable
Every step is a proof object with rule id and side conditions; the prose is generated from it.
Deterministic
Byte-identical output on every platform and compiler — diffable, cacheable, reproducible.
Safe
Budgeted & cancellable everywhere, so user-supplied formulas can't hang or crash a host.
Portable
Zero deps, permissive, headless C ABI — links into anything, offline, from server to phone.

The real leverage

Combinations only ckmath makes possible

Auditable math
Deterministic + conditioned + traced = a result whose derivation is exportable and re-verifiable bit-for-bit. For regulated, engineering, and financial work that must show why and under what conditions.
Distributed & cached math
Byte-determinism lets you memoize by canonical form and guarantee server and client agree exactly — reproducible scientific documents, cross-platform goldens.
Safe user formulas
Bounded evaluation makes “let end users type formulas” — spreadsheets, validators, low-code rule engines — safe by construction.
Trustworthy AI math
The assistant-outside-the-trust-boundary design is the missing piece that makes “the model did the math” something you can stand behind.

What not to build on it

Not a research CAS
No Risch integration, Gröbner bases, ODE/PDE, theorem proving, or exhaustive special functions.
Not a numerics powerhouse
No arbitrary-precision floats yet, no BLAS/LAPACK scale, no FFT-class bignum — bring your own for heavy compute.
Not graphics or typesetting
It hands you correct data to plot and semantic forms to typeset; pixels and glyphs are yours.
Not a language or notebook runtime
Definitions only — no loops, no I/O, no user native code.

Arbitrary-precision floating point

Today ckmath is exact (integers, rationals, symbols) or IEEE double — nothing between. An owned big-float behind the existing numeric-mode seam (double-double first, then a true arbitrary-precision float — deliberately never an LGPL dependency) would let a computation ask for N correct digits instead of a machine double.

  • Deep-zoom function graphing — pan and zoom a plot arbitrarily far without the curve dissolving into floating-point noise.
  • Verified numeric tables & constants — physical constants, quadrature, and special values computed to a requested precision and pinned.
  • High-precision scientific & engineering compute — models where a double's 15–16 digits are simply not enough.
  • Finance & actuarial at any scale — long-horizon or large-magnitude models where rounding is unacceptable.
  • Oracle-grade internal evaluation — raise ckmath's own verification precision, tightening every quality claim it makes.
  • Ill-conditioned & chaotic exploration — study systems where doubles silently diverge from the truth.

Sequencing

If you're choosing where to start

Ship the trust story first; add breadth as tracks land.

The exact-spreadsheet + computed-document + step-by-step-tutor trio is essentially ready on the recovered 1.0 spine — arithmetic, differentiation, conditioned simplification, rendering, and traces already carry it. Broad symbolic integration and solving and linear-algebra apps wait on the 1.x tracks; treat them as the second wave.

The two applications worth planting a flag on are the ones nothing off-the-shelf gives you cleanly: the checkable step-by-step tutor, built on replayable machine-checked traces, and the trustworthy-AI-math oracle, built on determinism plus the assistant trust boundary. Of the Phase 2 pieces, arbitrary-precision floats and a units layer give the widest new reach for the least conceptual departure from what ckmath already is.
